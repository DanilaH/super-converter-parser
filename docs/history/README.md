# Frozen project history

Everything under this directory is a **frozen historical record**.

These files preserve old implementation plans, release/feature acceptance evidence, methodology reports, and the reasoning that existed when each track was active. They are useful for archaeology and rationale, but they are not current runtime contracts or current backlog.

Status words inside an archived file are contextual to the time it was authored. For current work, follow the root `README.md`, `AGENTS.md`, `PRODUCT.md`, `ARCHITECTURE.md`, `PIPELINE.md`, and the relevant narrow current contract.

Do not “refresh” historical records to make them describe the latest implementation. Fix current root documentation instead.
