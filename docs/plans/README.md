# Inactive future plans

Files under this directory are **planning material, not current backlog or runtime contracts**.

The currently active development sequence lives at [`../../ROADMAP.md`](../../ROADMAP.md). Keeping it at the repository root is deliberate: placing active work here would make the `docs/plans/` inactive/future taxonomy ambiguous.

A future plan becomes active only when a current root contract, the current roadmap, or an explicit new task says that track has been activated. Until then, do not implement it merely because a planning document calls itself a source of truth for a future version.

Activation must be explicit and scoped. It does not automatically promote every neighboring future plan or stale provider assumption into current requirements.

Provider/access assumptions in planning documents must be re-verified before implementation because external services, quotas, terms, and APIs can change.
